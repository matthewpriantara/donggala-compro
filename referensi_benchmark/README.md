# Dataset & Direktori Tangkapan Layar Benchmark Portal Wisata KKN
## Koleksi Referensi Visual & Pelatihan Model AI (UI/UX Dataset)

Direktori ini (`compro/referensi_benchmark/`) berisi **arsip tangkapan layar penuh (full-page high-resolution screenshots)** untuk versi **Desktop (1440px)** dan **Mobile (390px)** dari seluruh portal benchmark desa binaan KKN-PPM UGM sesuai dengan dokumen `@file:compro/REFERENSI.md` serta portal mitra terkait.

Dataset ini dirancang khusus untuk:
1. **Patokan Referensi Desain (*Design Benchmark*)**: Acuan langsung tata letak, hirarki visual, kombinasi warna, dan komponen interaktif dalam perancangan website **Donggala (Towale & Limboro)**.
2. **Wadah Pelatihan Model AI (*AI Model Training / Fine-Tuning / Few-Shot Prompting*)**: Dataset pasangan citra antarmuka (*UI Screenshots*) + metadata JSON (*layouting, color systems, copywriting, component architecture*) untuk melatih atau memandu model AI vision-to-code / design reasoning.

## 🧠 Panduan Penggunaan untuk Model Training & Evaluasi Desain

1. **Format File:** Citra PNG tanpa kompresi *lossy* yang mempertahankan detail teks, rendering font, dan tata letak asli pada rasio piksel nyata.
2. **Metadata Mesin (*Machine-Readable*):** File `metadata.json` di folder ini menyediakan skema JSON terstruktur untuk ingest otomatis ke *data pipeline* atau *training dataset* model multimodal (VLM / LLM).
3. **Standar Ekstraksi:**
   - **Desktop Viewport:** 1440 × Variabel Tinggi Halaman (Full-Page Capture).
   - **Mobile Viewport:** 390 × Variabel Tinggi Halaman (Full-Page Capture, iPhone Profile).
